# 영어 대화 · 단어 학습

한국어 사용자를 위한 영어 연습 페이지입니다. Alex와 짧게 대화하고, 같은 자리에서 단어를 외울 수 있습니다.

## 실행

Ruby가 설치된 터미널에서 프로젝트 폴더로 이동한 뒤 서버를 켭니다.

```bash
ruby server.rb
```

브라우저에서 [http://127.0.0.1:8782](http://127.0.0.1:8782) 를 엽니다.

## OpenAI 키

대화 기능은 OpenAI를 사용합니다. 프로젝트 폴더에 `.env` 파일을 만들고 키를 넣습니다.

```text
OPENAI_API_KEY=여기에_키를_입력
```

`.env`는 Git에 올라가지 않습니다. 키가 없거나 크레딧이 없으면 대화 답변만 동작하지 않고, 단어 학습은 그대로 쓸 수 있습니다.

## 화면

- **영어 대화** (`index.html`): 주제 선택, 쉬운 영어, 답 읽어 주기, 마이크 입력을 지원합니다. 마이크는 Chrome 또는 Edge에서 사용할 수 있습니다.
- **단어 학습** (`words.html`): 카드, 뜻 고르기, 철자 쓰기. 외운 표시와 직접 추가한 단어는 이 브라우저에만 저장됩니다.

단어 학습만 쓸 때는 `words.html`을 브라우저로 직접 열어도 됩니다. 대화는 `ruby server.rb`로 연 주소에서만 동작합니다.
